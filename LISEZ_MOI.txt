2. COMMENT VISUALISER LE SITE IMMEDIATEMENT :
--------------------------------------------------------------------------------
- Méthode 1 : Double-cliquez sur "DEMARRER_LE_SITE.bat" (sous Windows).
- Méthode 2 : Double-cliquez directement sur "index.html" dans votre explorateur.
Le site s'ouvre directement dans votre navigateur (Chrome, Edge, Firefox, Safari).

--------------------------------------------------------------------------------
3. COMMENT EDITER LE CODE DANS VISUAL STUDIO CODE :
--------------------------------------------------------------------------------
1. Ouvrez Visual Studio Code.
2. Allez dans le menu : Fichier > Ouvrir le dossier... (File > Open Folder...).
3. Sélectionnez le dossier décompressé "patco-gesign-studio".
4. Vous pouvez modifier n'importe quel fichier (.html, .css, .js).
   (Astuce : Installez l'extension "Live Server" dans VS Code pour voir
   vos modifications se recharger automatiquement à chaque enregistrement).
